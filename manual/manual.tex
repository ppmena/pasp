\section{Introduction}

\begin{tcolorbox}[colback=backcolour,colframe=primary,title=Project Philosophy]
PASP (Portable Android Statistics Program) is a lightweight, local, interactive command-line interface (CLI) statistical analysis program. Designed specifically to work in terminal-restricted environments like \textbf{Android Termux}, it is fully cross-platform and compatible with any desktop operating system (Linux, macOS, Windows).
\end{tcolorbox}

The philosophy of PASP is inspired by \textbf{JASP} (Jeffrey's Amazing Statistics Program), emphasizing:
\begin{itemize}
    \item \textbf{Scientific Rigor:} Strict, automated assumption checking (normality, homogeneity, outlier detection).
    \item \textbf{Adaptive Workflows:} Transparent, automated fallback to robust or non-parametric alternatives when assumptions are violated.
    \item \textbf{Mobile-First Optimization:} Fast CLI startup via \emph{Lazy Loading} of heavy mathematical dependencies, plain-text fallbacks, and beautiful APA-styled tabular terminal outputs using Unicode characters.
    \item \textbf{Ease of Use:} Native support for variable column index referencing instead of full string names.
\end{itemize}

\section{System Architecture \& Installation}

\subsection{Dependencies}
PASP requires a Python 3.7+ environment and relies on the standard Python scientific stack:
\begin{itemize}
    \item \textbf{pandas} (Data handling, encoding/delimiter auto-detection)
    \item \textbf{numpy} (Array manipulations)
    \item \textbf{scipy} (Statistical test engines)
    \item \textbf{statsmodels} (Residual diagnostics, outlier evaluation, robust metrics)
    \item \textbf{rich} (Terminal table formatting)
\end{itemize}

\subsection{Standard Installation}
To install PASP on any modern operating system:
\begin{lstlisting}[language=bash]
pip install git+https://github.com/ppmena/PASP
\end{lstlisting}

\subsection{Android Termux Setup}
Termux requires setting up system libraries before compiling SciPy/Pandas:
\begin{lstlisting}[language=bash]
pkg update && pkg upgrade
pkg install python clang make cmake pkg-config ninja meson
pip install --no-build-isolation git+https://github.com/ppmena/PASP
\end{lstlisting}

\subsection{Diagnostic \& Help Commands}
\begin{itemize}
    \item \texttt{pasp doctor}: Validates your installation, system paths, and dependencies.
    \item \texttt{pasp install-help}: Displays detailed, platform-specific guides.
    \item \texttt{pasp examples}: Lists example CSV files bundled with the package.
\end{itemize}

\section{Command Line Interface (CLI)}

PASP supports two flexible interaction styles.

\subsection{Style A: Direct Usage}
\begin{lstlisting}[language=bash]
pasp [file] [flags] [arguments]
\end{lstlisting}
\textbf{Examples:}
\begin{lstlisting}[language=bash]
pasp data.csv --auto
pasp data.csv --anova score group --plot
pasp data.csv --descriptives --vars age income
\end{lstlisting}

\subsection{Style B: Subcommands}
\begin{lstlisting}[language=bash]
pasp [subcommand] [file] [arguments]
\end{lstlisting}
\textbf{Examples:}
\begin{lstlisting}[language=bash]
pasp descriptives data.csv
pasp ttest-ind data.csv score group --plot
pasp chi-square data.csv gender profession
\end{lstlisting}

\section{Variable Classification \& Descriptives}

\subsection{Variable Classification Rules}
PASP dynamically classifies variables based on data types and frequency properties:
\begin{itemize}
    \item \textbf{Nominal:} Text columns, booleans, or objects.
    \item \textbf{Ordinal:} Integers or numeric columns with $\leq 4$ unique values.
    \item \textbf{Scale:} Continuous numeric columns with $> 4$ unique values.
\end{itemize}
\emph{Note: Nominal variables omit continuous tendencies like Mean and SD; mode and frequencies are reported instead.}

\subsection{The --plot Flag for Descriptives}
Enabling \texttt{--plot} on descriptives generates high-fidelity vertical histograms using terminal-friendly block symbols (\texttt{█}) for all numeric scale variables, showing the density distribution clearly.

\section{Statistical Methods \& Technical Formulations}

\subsection{Independent Samples T-Test}
Calculates differences between two group means.
\begin{itemize}
    \item \textbf{Assumption Check:} Normal distribution of both group samples via Shapiro-Wilk:
    \begin{equation}
    W = \frac{\left(\sum_{i=1}^n a_i x_{(i)}\right)^2}{\sum_{i=1}^n (x_i - \bar{x})^2}
    \end{equation}
    And homogeneity of variance using Levene's test ($p > 0.05$).
    \item \textbf{Fallback:}
    \begin{itemize}
        \item If normal but heterogeneous variance: Uses \textbf{Welch's T-Test}.
        \item If non-normal: Automatically falls back to \textbf{Mann-Whitney U Test} and reports Rank-Biserial $r$ as effect size.
    \end{itemize}
    \item \textbf{Force Option:} Bypasses these fallbacks with \texttt{--force-parametric} to strictly calculate the Student's T-Test.
    \item \textbf{Visual Plot:} Generates comparative overlapping block-histograms highlighting group distribution overlaps.
\end{itemize}

\subsection{One-way ANOVA}
Performs analysis of variance across $\geq 2$ groups.
\begin{itemize}
    \item \textbf{Verification Protocol:} Tests model residuals for normality and evaluates homogeneity with Levene. Outliers are flagged if standardized residuals $|z| > 3$.
    \item \textbf{Non-parametric Alternative:} Automatically runs the \textbf{Kruskal-Wallis H Test} with **Dunn's Post-Hoc** test.
    \item \textbf{Post-Hoc comparisons:} Runs pairwise combinations using a pooled standard deviation and Bonferroni adjusted $p$-values.
    \item \textbf{Visual Plot:} Groups are plotted as horizontal boxplots.
\end{itemize}

\subsection{Chi-Square Test of Independence}
Evaluates the association between two nominal or ordinal variables.
\begin{itemize}
    \item \textbf{Model Math:} Calculates the Pearson Chi-Square statistic:
    \begin{equation}
    \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}
    \end{equation}
    \item \textbf{Effect Size:} Cramer's $V$:
    \begin{equation}
    V = \sqrt{\frac{\chi^2}{N(k - 1)}}
    \end{equation}
    \item \textbf{Post-Hoc Analysis:} Evaluates adjusted standardized residuals for each cell. High residuals ($|z| > 1.96$) indicate cells driving the dependence.
\end{itemize}
